Plisto mock host

This is a mock, not Plisto. It answers the SDK with canned data: a small fixed library, an in-memory store, a fake transport. It applies no real sandbox policy (no content security policy, no rate budgets, only part of the argument checks), and it does not run native programs.

A page that works here is not proven. The real check is installing the plugin in Plisto and testing it there.

Examples: hello-ui hello-background tap-meter page

Host

Theme, visibility and route are sent as events. A page that subscribed also gets the theme, locale and app_mode topics when these controls change; language and app mode are otherwise read at start, so reload to apply. The library buttons reach a page subscribed to library_changed.

Transport

Stream

Sends a stream event to the page, as Plisto does for the plugin's own stream. An ended event also clears the fake stream.
